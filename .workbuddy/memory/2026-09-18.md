## 工具链踩坑（重要，已沉淀为 skill）

- **Bash 工具在本机不可用**（shim 报 `dirname: command not found` / `mkdir: command not found`），必须改用 PowerShell 工具
- **PowerShell 工具不直接回显 stdout**，必须 `| Out-File -Encoding utf8` 落盘后用 Read 工具读取
- **必须先设 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`**，否则中文输出变乱码
- **westock-tool** 选股 CLI：`node <skill>/scripts/index.js filter/strategy/ranking/label/event`
  - `filter` 表达式：多条件必须 `intersect([a, b])`，**不支持 `&`/`&&`/`AND`**
  - **`TotalMV` 筛选单位是「元」**（但输出展示为亿元）——写 60 是错的，要写 6000000000
  - **均线字段名带下划线**：`MA_5`/`MA_10`/`MA_20`/`MA_60`，写成 `MA5` 直接返回空
  - 可用字段：PE_TTM / PB / ROETTM / DividendRatioTTM / TORGrowRate / DebtAssetsRatio / NetOperateCashFlow / MainNetFlow / MainNetFlow5D / TurnoverValue / TurnoverRate / Chg5D/10D/20D/60D / NegotiableMV
  - 表达式里写到的字段才会出现在返回列中——想多看某字段就把它加进条件（如 `NegotiableMV > 0`）
- **westock-data** 行情 CLI：需先 `node scripts/setup.cjs` 安装到 `C:\Users\PC\.local\bin\westock.exe`，之后用 `westock quote code1,code2` 批量取快照
- **主板代码前缀**：沪市 600/601/603/605，深市 000/001/002/003；排除 300/301（创业板）、688/689（科创板）、8xx/4xx（北交所）
